# Security Policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** action on this repository to send a private security advisory. Do not report vulnerabilities in public issues or discussions.

Include the affected package version or commit, the impact, steps to reproduce, and any safe mitigation you know. The maintainers will coordinate investigation and disclosure through the private advisory.

If GitHub's private reporting action is unavailable, contact a Digit7s organization owner privately before sharing vulnerability details publicly.
